# Вход в MAXIMUM Education

Скрипты открывают личный кабинет MAXIMUM Education через 20.35 и Leader-ID.
В конце всегда открывается страница «Мои курсы»:

https://education.maximumtest.ru/student/courses

Скрипты только выполняют вход. Они не решают домашние задания и не обходят капчу.

## Две версии

| Папка | Система | Браузер |
|---|---|---|
| `windows_chrome` | Windows | Google Chrome |
| `mac_yandex` | macOS | Yandex Browser |

В обеих папках одинаковые скрипты. Разница только в `config.json`: пути к профилям и браузеру.

### Файлы в каждой папке

- `config.json` — аккаунты и настройки.
- `setup_sessions.py` — один раз настраивает вход для каждого аккаунта.
- `quick_login.py` — открывает все аккаунты сразу в отдельных окнах.
- `requirements.txt` — библиотеки Python.

## Как работает вход

1. Открывается страница курсов MAXIMUM.
2. Нажимается кнопка «Войти через 20.35 Университет».
3. Открывается Leader-ID.
4. Страница входа перезагружается 2 раза.
5. Вводятся логин и пароль из `config.json`.
6. Если появилась капча, скрипт ждёт, пока вы решите её вручную.
7. После входа открывается страница «Мои курсы».

Для каждого аккаунта создаётся отдельный профиль браузера. В нём сохраняется сессия.
Поэтому `setup_sessions.py` нужен только один раз.

Сессии не переносятся между Windows и Mac. На каждой системе вход нужно настроить один раз.

## Быстрый старт на Windows

1. Установите Python 3.11 или новее с сайта python.org. При установке включите `Add Python to PATH`.
2. Откройте PowerShell в папке `windows_chrome`.
3. Выполните:

```
 создайте окружение:

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe setup_sessions.py
```

4. Пройдите вход по каждому аккаунту. Когда появится капча, решите её в окне браузера.
5. После успешного входа нажмите Enter в терминале. Откроется следующий аккаунт.

Ежедневный запуск:

```
..\.venv\Scripts\python.exe quick_login.py
```

или, если окружение внутри папки:

```
.venv\Scripts\python.exe quick_login.py
```

## Быстрый старт на Mac

1. Установите Python 3.11 или новее. Проверка: `python3 --version`.
2. Установите Yandex Browser в папку «Программы» (`/Applications`).
3. Откройте Terminal в папке `mac_yandex`.
4. Создайте окружение и установите библиотеки:

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

5. Установите ChromeDriver, который подходит к Yandex Browser.
6. Запустите настройку:

```
python setup_sessions.py
```

7. Пройдите вход и капчу. После успеха нажмите Enter.

Ежедневный запуск (из папки `mac_yandex`):

```
source .venv/bin/activate
python quick_login.py
```

### ChromeDriver для Yandex Browser на Mac

Yandex Browser работает на Chromium, поэтому для него нужен ChromeDriver той же версии.

1. Откройте Yandex Browser.
2. В адресной строке введите `yandex://version` и нажмите Enter.
3. Найдите строку `Chromium`. Например: `Chromium: 130.0.6723.58`.
4. Откройте https://googlechromelabs.github.io/chrome-for-testing/
5. Скачайте ChromeDriver с такой же версией:
   - `mac-arm64` — если процессор Apple (M1, M2, M3 и другие);
6. Распакуйте архив, например в `/Users/ваш_логин/chromedriver/chromedriver`.
7. Выполните в Terminal:

```
chmod +x ~/chromedriver/chromedriver
xattr -d com.apple.quarantine ~/chromedriver/chromedriver
```

8. В `mac_yandex/config.json` укажите полный путь:

```
"driver_path": "/Users/ВАШ_ЛОГИН/chromedriver/chromedriver"
```

Если ChromeDriver уже установлен через Homebrew и его версия совпадает, поле `driver_path` можно оставить пустым. Скрипт сам проверит `/opt/homebrew/bin/chromedriver` и `/usr/local/bin/chromedriver`.

### Если Yandex установлен в другом месте

Стандартный путь:

```
/Applications/Yandex.app/Contents/MacOS/Yandex
```

Если браузер лежит в другом месте, измените `browser_binary` в `mac_yandex/config.json`.

## Настройка config.json

```json
{
  "target_url": "https://education.maximumtest.ru/student/courses",
  "profiles_dir": "...",
  "browser_binary": "",
  "driver_path": "",
  "accounts": [
    {
      "name": "Аккаунт 1",
      "email": "mail@example.com",
      "password": "пароль",
      "profile": "account1",
      "enabled": true
    }
  ]
}
```

- `target_url` — страница, на которой должен закончиться вход. Менять не нужно.
- `profiles_dir` — папка с профилями браузера. Менять не нужно.
- `browser_binary` — путь к браузеру. Пусто = Chrome. На Mac уже указан Yandex.
- `driver_path` — путь к ChromeDriver. Пусто = искать автоматически.
- `name` — имя для вывода в консоли.
- `email` и `password` — данные для входа.
- `profile` — имя папки профиля. У каждого аккаунта должно быть своё.
- `enabled` — `true` включает аккаунт, `false` выключает.

Аккаунты с пустыми `email` или `password` пропускаются.

Пароли хранятся в `config.json` в открытом виде. Не передавайте эту папку другим людям.

## Что произойдёт при запуске setup_sessions.py

Скрипт берёт аккаунты по порядку из `config.json`.

Для каждого аккаунта:

1. Открывает отдельное окно браузера.
2. Переходит на страницу курсов MAXIMUM.
3. Нажимает «Войти через 20.35 Университет».
4. Ждёт страницу Leader-ID и 2 раза её перезагружает.
5. Вводит email и пароль.
6. Ждёт, пока вы решите капчу (до 5 минут).
7. Нажимает «Войти».
8. Дожидается страницы «Мои курсы».
9. Оставляет окно открытым. Нажмите Enter в терминале, чтобы закрыть его и перейти к следующему аккаунту.

Если вход не удался, скрипт спросит:

- `r` — повторить;
- `s` — пропустить;
- `q` — выйти.

## Что произойдёт при запуске quick_login.py

1. Скрипт читает аккаунты из `config.json`.
2. Для каждого включённого аккаунта открывает отдельное окно браузера с его профилем.
3. Открывает страницу «Мои курсы».
4. Окна остаются открытыми. Можно работать в них вручную.
5. Нажмите Enter в терминале, чтобы закрыть все окна. Если терминала нет, окна останутся открытыми, пока вы не закроете их сами.

Если сессия аккаунта истекла, `quick_login.py` напишет об этом и предложит запустить `setup_sessions.py`.

Если вход не удался, скрипт сохраняет скриншот и страницу в папку `logs` рядом со скриптом. Это помогает понять причину ошибки.



- Скрипты не обходят капчу. Её всегда нужно решать вручную.
- Скрипты не решают и не отправляют домашние задания. Они только выполняют вход.
- Не запускайте два окна с одним и тем же профилем одновременно.
- Если сайт изменит оформление, скрипты могут перестать находить нужные кнопки.
