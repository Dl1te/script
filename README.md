# Вход в MAXIMUM Education

Скрипты для автоматизации входа в личный кабинет MAXIMUM Education через системы 20.35 и Leader-ID.
В конце успешного входа всегда открывается страница «Мои курсы»:
`https://education.maximumtest.ru/student/courses`

> **Важно:** Скрипты выполняют только вход. Они не решают домашние задания и не обходят капчу. Капчу всегда нужно решать вручную.

## Структура проекта

Проект разделён на две версии под разные операционные системы и браузеры. Внутри папок лежат одинаковые скрипты, отличается только файл конфигурации.

| Папка | Операционная система | Браузер |
| :--- | :--- | :--- |
| `windows_chrome` | Windows | Google Chrome |
| `mac_yandex` | macOS | Yandex Browser |

### Файлы в каждой папке

- `config.json` — аккаунты и настройки.
- `setup_sessions.py` — первичная настройка входа для каждого аккаунта.
- `quick_login.py` — быстрый запуск всех аккаунтов сразу в отдельных окнах.
- `requirements.txt` — список библиотек Python.

### Папки с профилями

Для каждого аккаунта создаётся отдельный профиль браузера. В нём сохраняется сессия, поэтому повторно вводить пароль при каждом запуске не нужно.

- Windows: `%LOCALAPPDATA%\LeaderIdMultiLogin\profiles`
- macOS: `~/Library/Application Support/LeaderIdMultiLogin/profiles`

## Как работает вход

1. Открывается страница курсов MAXIMUM.
2. Нажимается кнопка «Войти через 20.35 Университет».
3. Открывается страница авторизации Leader-ID.
4. Страница входа перезагружается 2 раза.
5. Вводятся логин и пароль из `config.json`.
6. Если появляется капча, скрипт ожидает её ручного решения.
7. После успешного входа открывается страница «Мои курсы».

Для каждого аккаунта создаётся отдельный профиль браузера, в котором сохраняется сессия. Поэтому скрипт `setup_sessions.py` достаточно запустить только один раз.

> **Обратите внимание:** Сессии не переносятся между Windows и Mac. На каждой системе вход нужно настроить отдельно.

## Быстрый старт на Windows

1. Установите Python 3.11 или новее с [официального сайта](https://python.org). При установке обязательно включите галочку `Add Python to PATH`.
2. Откройте PowerShell в папке `windows_chrome`.
3. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Запустите настройку сессий:

```bash
.venv\Scripts\python.exe setup_sessions.py
```

5. Пройдите вход по каждому аккаунту. Когда появится капча, решите её в окне браузера.
6. После успешного входа нажмите Enter в терминале. Окно закроется, и скрипт перейдёт к следующему аккаунту.

> Если в корне проекта уже есть готовая папка `.venv`, создавать новую не нужно. Тогда запускайте скрипты так:
> `..\.venv\Scripts\python.exe setup_sessions.py`

### Ежедневный запуск

```bash
.venv\Scripts\python.exe quick_login.py
```

Если используется окружение из корня проекта:

```bash
..\.venv\Scripts\python.exe quick_login.py
```

## Быстрый старт на Mac

1. Установите Python 3.11 или новее. Проверка: `python3 --version`.
2. Установите Yandex Browser в папку «Программы» (`/Applications`).
3. Откройте Terminal в папке `mac_yandex`.
4. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

5. Установите ChromeDriver, который подходит к Yandex Browser (см. ниже).
6. Запустите настройку сессий:

```bash
python setup_sessions.py
```

7. Пройдите вход и капчу. После успешного входа нажмите Enter.

### Установка ChromeDriver для Yandex Browser

Yandex Browser работает на Chromium, поэтому для него нужен ChromeDriver той же версии.

1. Откройте Yandex Browser.
2. В адресной строке введите `yandex://version` и нажмите Enter.
3. Найдите строку `Chromium`. Например: `Chromium: 130.0.6723.58`.
4. Откройте [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/).
5. Скачайте ChromeDriver с такой же версией:
   - `mac-arm64` — если процессор Apple (M1, M2, M3 и другие);
   - `mac-x64` — если процессор Intel.

   Проверить процессор можно в меню Apple → «Об этом Mac» → «Чип» или командой `uname -m`.
6. Распакуйте архив, например в `/Users/ВАШ_ЛОГИН/chromedriver/chromedriver`.
7. Выполните в Terminal:

```bash
chmod +x ~/chromedriver/chromedriver
xattr -d com.apple.quarantine ~/chromedriver/chromedriver
```

8. В `mac_yandex/config.json` укажите полный путь:

```json
"driver_path": "/Users/ВАШ_ЛОГИН/chromedriver/chromedriver"
```

Если ChromeDriver уже установлен через Homebrew и его версия совпадает, поле `driver_path` можно оставить пустым. Скрипт сам проверит `/opt/homebrew/bin/chromedriver` и `/usr/local/bin/chromedriver`.

### Если Yandex установлен в другом месте

Стандартный путь:

```text
/Applications/Yandex.app/Contents/MacOS/Yandex
```

Если браузер лежит в другом месте, измените `browser_binary` в `mac_yandex/config.json`.

### Ежедневный запуск

Из папки `mac_yandex`:

```bash
source .venv/bin/activate
python quick_login.py
```

## Настройка config.json

Файл `config.json` лежит в папке каждой версии. Пример:

```json
{
  "target_url": "https://education.maximumtest.ru/student/courses",
  "profiles_dir": "%LOCALAPPDATA%/LeaderIdMultiLogin/profiles",
  "browser_binary": "",
  "driver_path": "",
  "accounts": [
    {
      "name": "Аккаунт 1",
      "email": "mail@example.com",
      "password": "пароль",
      "profile": "account1",
      "enabled": true
    }
  ]
}
```

### Основные поля

| Поле | Что означает |
| :--- | :--- |
| `target_url` | Страница, на которой должен закончиться вход. Менять не нужно. |
| `profiles_dir` | Папка с профилями браузера. Менять не нужно. |
| `browser_binary` | Путь к браузеру. Пусто — Google Chrome. На Mac уже указан Yandex Browser. |
| `driver_path` | Путь к ChromeDriver. Пусто — искать автоматически. |
| `name` | Имя аккаунта для вывода в консоли. |
| `email` | Логин от Leader-ID. |
| `password` | Пароль от Leader-ID. |
| `profile` | Имя папки профиля. У каждого аккаунта должно быть своё. |
| `enabled` | `true` — включить аккаунт, `false` — выключить. |

Остальные поля в конфиге технические: таймауты, размеры окон и задержки. Их можно не менять.

### Что важно знать

- Аккаунты с пустыми `email` или `password` пропускаются.
- У каждого аккаунта должно быть уникальное значение `profile`.
- Пароли хранятся в `config.json` в открытом виде. Не передавайте папку с конфигом другим людям.
- Не копируйте `config.json` между Windows и Mac: пути к профилям и браузеру в них разные.

## Описание скриптов

### setup_sessions.py

Нужен для первого входа и сохранения сессии.

Что делает:

1. Берёт аккаунты по порядку из `config.json`.
2. Открывает отдельное окно браузера для каждого аккаунта.
3. Проходит цепочку MAXIMUM → 20.35 → Leader-ID.
4. Дважды перезагружает страницу входа.
5. Вводит email и пароль.
6. Ждёт ручного решения капчи до 5 минут.
7. Дожидается страницы «Мои курсы».
8. Оставляет окно открытым, пока вы не нажмёте Enter.

Если вход не удался, скрипт предложит выбор:

- `r` — повторить;
- `s` — пропустить аккаунт;
- `q` — завершить настройку.

### quick_login.py

Нужен для ежедневного входа.

Что делает:

1. Читает аккаунты из `config.json`.
2. Открывает для каждого включённого аккаунта отдельное окно браузера.
3. Открывает страницу «Мои курсы».
4. Оставляет окна открытыми, чтобы в них можно было работать.
5. Закрывает все окна после нажатия Enter в терминале. Если терминала нет, окна остаются открытыми, пока вы не закроете их сами.

Если сессия аккаунта истекла, скрипт напишет об этом и предложит снова запустить `setup_sessions.py`.

Если вход не удался, скрипт сохраняет скриншот и страницу в папку `logs` рядом со скриптом.

## Ограничения и предупреждения

- **Капча.** Скрипты не обходят и не решают капчу. Её всегда нужно проходить вручную.
- **Домашние задания.** Скрипты не решают и не отправляют задания. Они только выполняют вход в аккаунт.
- **Сессии.** Сохранённые сессии не переносятся между Windows и Mac.
- **Один профиль — одно окно.** Не запускайте два окна с одним и тем же профилем одновременно. Если появилась ошибка `user data directory is already in use`, закройте старое окно браузера.
- **Изменения на сайте.** Если MAXIMUM изменит оформление страниц, скрипты могут перестать находить нужные кнопки.
- **Пароли.** Папка `config.json` содержит пароли в открытом виде. Храните её в безопасном месте.
